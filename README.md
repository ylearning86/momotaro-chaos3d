# 桃太郎カオス3D

正規の桃太郎を土台にしつつ、要所で別の選択を行える3D分岐アプリです。

## 遊び方

1. momotaro-chaos3d/index.html をブラウザで開く
2. 序章は「桃の中」から開始。E を押して桃太郎を誕生させる
3. その後は WASD で移動、Space でジャンプ、Shift でダッシュ
4. 仲間の近くで E を押す
5. 選択イベントが出たら 1 または 2 で分岐を選ぶ
6. 鬼ヶ島の城で最後の選択をすると結末が確定

## マップ構成

- 川（桃が流れる）
- おじいさん・おばあさんの村
- 山道
- 海辺と舟
- 鬼ヶ島

正規の桃太郎の流れを意識した並びで進行します。

## 分岐の考え方

- きびだんごの場面
- 海渡りの場面
- 鬼ヶ島決戦の場面

上の3か所で「正規寄り」と「別選択」を選べます。
正規寄りの選択を積み重ねると、昔話に近い結末になりやすくなります。

## 操作メモ

- Q: その場回転（ゆがみ度が上がりやすい）
- R: リセット
